# Split V — minimal application guidelines

Approved mark: `industrial_ai/assets/brand.svg`. Brand blue: `#1f6cf5`. For inline SVG on dark surfaces, use the same paths in white; never place the fixed-blue file on a similarly blue background.

Keep the 256×256 viewBox and aspect ratio. Minimum screen size: 16×16 px. Built-in padding is 32 units horizontally and 40 vertically; retain it for favicon and navigation use. Do not add gradients, strokes, shadows, stretching, rotation or details inside the V.

The application name remains normal interface text next to the symbol. No custom wordmark or additional logo kit is included.
